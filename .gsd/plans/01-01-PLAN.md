<task type="auto">
  <name>Task 4: Selector Resolver with fallback chain</name>
  <files>src/selector-resolver.ts</files>
  <action>
    Create `src/selector-resolver.ts`:
    - `resolveSelector(page: Page, command: LLMCommand, domContext: DOMSnapshot): Promise<Locator | null>`
    - Strategy 1: Use LLM's exact CSS selector (confidence > 0.8)
    - Strategy 2: Semantic — page.getByRole(command.role, { name: command.text })
    - Strategy 3: Text — page.getByText(command.text, { exact: false })
    - Strategy 4: testId — page.getByTestId(command.testId)
    - Strategy 5: CSS fallback (last resort)
    - Each strategy checks isVisible() before returning
    - Returns null if all strategies fail
    - Logs which strategy was used for debugging
  </action>
  <verify>bun test passes, selector resolver handles all fallback strategies correctly</verify>
  <done>src/selector-resolver.ts compiles, unit tests pass</done>
</task>
