# Plan 01-03: Phase 3 — Selector Intelligence

## Phase Overview
Goal: Make selectors self-heal when the first attempt fails. Add screenshot-based vision as a last-resort strategy.

## Phase 2 Issue to Fix
`"query the page title text"` failed because:
- The LLM returned h1 with confidence=1 but the selector resolver couldn't find it via role+text fallback
- The DOM snapshot was serialized at start of ai() call, so the LLM's h1 selector was checked against elements that may not have matched

**Fix needed:** Selector retry with context enrichment + self-healing.
