# Plan 01-04: Phase 4 — Vision + Multi-page + Recording

## Phase Overview
Goal: Enable vision-aware prompts, multi-page flows, and a recording mode that captures user actions and generates `ai()` code.

## Context from Research
ZeroStep captures both a screenshot AND DOM snapshot, then sends both to the LLM.
This allows the LLM to see what the page actually looks like, not just what the DOM says.
For complex UIs with CSS-drawn elements, overlapping layers, or dynamic content,
vision + DOM fusion is significantly more reliable.

## Phase 4 Issue from Phase 3
The vision module exists (src/vision.ts) but is disabled by default.
Phase 4 enables it and integrates it into the ai() call pipeline.

    Add first-class support for Page Object pattern with AI:
    
    ```typescript
    // src/page-object.ts
    import { test, type Page } from '@playwright/test'
    import { ai } from './ai'
    
    // Create an AI-powered page object
    export class AiPageObject {
      constructor(
        protected page: Page,
        protected options?: { baseUrl?: string; selectorPrefix?: string }
      ) {}
      
      // Define page sections as methods that use ai()
      async section(name: string, instruction: string): Promise<void> {
        await ai(instruction, { page: this.page })
      }
      
      // Common AI actions as typed methods
      async click(label: string): Promise<void> {
        await ai(`click the ${label}`, { page: this.page })
      }
      async type(label: string, value: string): Promise<void> {
        await ai(`type "${value}" in the ${label}`, { page: this.page })
      }
      async assert(label: string): Promise<boolean> {
        return await ai(`assert the ${label} is visible`, { page: this.page, type: 'assert' }) as boolean
      }
    }
    
    // Helper to create a typed page object bound to a specific URL
    export function createPageObject<T extends AiPageObject>(
      cls: new (page: Page) => T,
      page: Page,
      url: string
    ): T {
      return new cls(page)
    }
    ```
    
    Example usage:
    ```typescript
    class LoginPage extends AiPageObject {
      async login(username: string, password: string) {
        await this.click('Sign In button')
        await this.type('email field', username)
        await this.type('password field', password)
        await this.click('submit button')
      }
    }
    
    test('login flow', async ({ page }) => {
      const login = createPageObject(LoginPage, page, '/login')
      await login.login('carlos@example.com', 'secret')
    })
    ```
